# 社内通知の確認表

Delta Chatのチャット内で社内のお知らせを共有し、本人が内容を確認したことを記録するwebxdcアプリです。チャットの既読とは別に「内容を確認しました」を押して記録し、確認済み・未確認者の一覧や期間別の集計をメンバーで共有できます。

## 配布アプリ

利用するファイルは **[Notice_Confirmation_Sheet_1.0.0.xdc](Notice_Confirmation_Sheet_1.0.0.xdc)** です。Delta Chatの共有したいチャットへ、このファイルを添付して送信してください。

| ファイル | 内容 |
| --- | --- |
| `Notice_Confirmation_Sheet_1.0.0.xdc` | バージョン番号付きの配布ファイル。アプリアイコンを同梱しています。 |
| `社内通知の確認表.xdc` | 先に作成した日本語名の配布ファイル。アイコンは同梱していません。 |

両ファイルの画面・操作・集計を担う`index.html`、`app.js`、`style.css`は同じ内容です。バージョン番号付きファイルには、追加の`icon.png`と、その指定を含む`manifest.toml`が入っています。

すでに日本語名のファイルで運用を始めている場合は、記録を続けるため、これまでのアプリの投稿を使ってください。別のファイルを送信しても、以前の確認記録は自動移行されません。

## 主な機能

- お知らせの作成：タイトル、本文、分類、確認期限、対象者を指定
- メンバーの参加登録と通知ごとの確認対象者の選択
- 本人の確認操作と確認日時の記録
- 確認済み・未確認者一覧の表示
- 自分の未確認通知の絞り込みとタイトル検索
- 年・月を指定した一覧、月別の確認状況グラフ
- 対象者ごとの記録をCSVで出力
- パソコン・スマートフォンに対応した画面

## はじめに

1. [Notice_Confirmation_Sheet_1.0.0.xdc](Notice_Confirmation_Sheet_1.0.0.xdc)を、共有したいDelta Chatのチャットへ添付して送信します。
2. 全員がそのアプリの投稿を開き、「メンバー」から「自分を参加登録」を押します。
3. お知らせを作る人は、全員の登録を確認してから「＋ お知らせを作成」を押します。
4. 内容・期限・確認対象者を指定し、「お知らせを共有」を押します。
5. 対象者は内容を読み、「内容を確認しました」を押します。「確認済み」と日時が表示されれば記録の反映は完了です。

**継続利用では、同じアプリの投稿を開いてください。** .xdcファイルを改めて送信すると別の確認表になり、以前の記録は引き継がれません。

## 確認状況を見る

「お知らせ」の各通知で「確認済み・未確認者の一覧を見る」を開くと、対象者の状況を確認できます。「自分の未確認」を選ぶと、自分が対象の未確認通知だけを表示します。

「記録・グラフ」では、年と月を選んで表示を絞れます。年間の記録を表示する場合は年を選び、月を「すべての月」にします。グラフの緑は確認済み、黄は未確認です。

確認率は、確認済みの件数を対象の確認件数で割って計算します。同じ人が複数の通知の対象なら、通知ごとに数えます。集計月は通知の作成月であり、確認した月ではありません。過去月も現在までの確認状況を表示し、月末時点の状態を固定する機能はありません。

## 毎月と毎年の運用

- 月初などに、その期間のお知らせを新しく作成します。定期通知の自動作成機能はありません。
- 確認期間中は未確認者一覧を確認し、必要に応じてチャットで案内します。自動催促機能はありません。
- 月末・年末には「記録・グラフ」で期間を指定し、「CSVを出力」で記録を保存します。
- CSVには保存日が分かる名前を付けて保管してください。CSVを読み込んでアプリの記録を復元する機能はありません。

## 利用上の注意

- 全員の参加登録が必要です。チャットのメンバー一覧は自動取得しません。未登録者は確認対象や未確認者一覧に入りません。
- 確認対象者は通知を作成した時点で固定されます。後から登録した人は過去の対象に追加されず、退出した人も過去の対象から自動的には外れません。
- 公開済み通知の編集・削除、確認の取り消し、対象者の変更はできません。訂正や追加が必要な場合は、新しい通知を作成してください。
- 確認は自己申告です。内容の理解度を判定する試験や、本人証明の電子署名ではありません。改造クライアントによる記録の偽装を防ぐ監査用途には適しません。
- 確認日時は操作した端末の時計に基づきます。
- 同期には通信が必要です。送信から反映まで時間がかかる場合があります。「共有待ち」などの表示がある場合は、反映を待って確認してください。
- 通知と記録は、このアプリを共有したチャットのメンバーに配信されます。社内で共有してよい情報を記載し、記録の保管ルールに従ってください。
- CSVの保存可否や保存先は、端末・クライアントによって異なります。チャットとアプリの投稿も保管してください。
